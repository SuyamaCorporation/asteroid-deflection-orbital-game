# 小惑星偏向軌道操作ゲーム

地球衝突コースの小惑星をKINETIC IMPACTORで軌道偏向させるシミュレーションゲーム。

## 概要

Canvas 600×400でリアルタイム軌道描画。小惑星が画面右から地球へ向かう軌道を表示し、プレイヤーがインパクトタイミング・角度・強度を選んでDEFLECTボタンで偏向弾を発射する。速度ベクトル変化を計算して軌道を再描画。地球命中でGAME OVER、偏向成功でクリア（次ステージへ）。

## 操作方法

- **インパクト角度スライダー**: -60°〜+60° で偏向弾の当たり角度を調整
- **インパクト強度スライダー**: 10〜100 で偏向力を調整
- **DEFLECT!ボタン**: 偏向弾を発射（残弾3発）
- **難易度選択**: EASY / NORMAL / HARD（小惑星速度・サイズ・偏向効率が変化）
- **NEW GAMEボタン**: スコアリセットして最初から

## 技術仕様

- バニラJS + Canvas 2D API
- requestAnimationFrameによるリアルタイムアニメーション
- 速度ベクトル演算による軌道偏向物理シミュレーション
- パーティクルエフェクト（爆発）
- 星空背景のプロシージャル生成
- 軌道予測ライン描画
